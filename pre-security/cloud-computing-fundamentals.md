# ☁️ Cloud Computing Fundamentals

> **Quick Summary:** Wprowadzenie do chmury obliczeniowej, modele wdrażania (Public, Private, Hybrid), modele świadczenia usług (IaaS, PaaS, SaaS), kluczowi dostawcy, podstawowa terminologia (AWS EC2) oraz korzyści z elastycznej infrastruktury.

---

## 🔑 Kluczowe Pojęcia (Key Terminology)

### 1. Modele Wdrażania Chmury (Cloud Deployment Models)
* **Public Cloud (Chmura Publiczna):** Usługi chmurowe dostępne przez Internet i oferowane wielu użytkownikom oraz organizacjom.
* **Private Cloud (Chmura Prywatna):** Infrastruktura chmurowa przeznaczona dla jednej konkretnej organizacji, zapewniająca większą kontrolę nad środowiskiem.
* **Hybrid Cloud (Chmura Hybrydowa):** Połączenie chmury publicznej i prywatnej, umożliwiające współdzielenie danych i aplikacji między nimi.

### 2. Modele Świadczenia Usług (Cloud Service Models)
* **IaaS (Infrastructure as a Service):** Wynajem podstawowych zasobów sprzętowych (serwery wirtualne, przestrzeń dyskowa, sieć). Użytkownik zarządza systemem operacyjnym i aplikacjami (np. AWS EC2).
* **PaaS (Platform as a Service):** Gotowe środowisko do tworzenia, testowania i wdrażania aplikacji bez konieczności zarządzania serwerami i systemem operacyjnym pod spodem.
* **SaaS (Software as a Service):** Gotowe oprogramowanie udostępniane użytkownikowi przez Internet, bez konieczności zarządzania jego infrastrukturą. (np. Gmail, Zoom).

### 3. Dostawcy i Terminologia (Vendors & Terminology)
* **Major Cloud Vendors:** Rynek chmurowy jest zdominowany przez dostawców takich jak Amazon Web Services (AWS), Microsoft Azure, Google Cloud Platform (GCP), Alibaba Cloud, IBM Cloud oraz Oracle Cloud.
* **AWS EC2 (Elastic Compute Cloud):** Usługa AWS umożliwiająca uruchamianie i zarządzanie instancjami obliczeniowymi w chmurze.
* **Instance Types (Typy Instancji):** Różne konfiguracje zasobów instancji, np. vCPU, pamięci RAM i przepustowości sieciowej (`t2`, `t3`, `m5`).

---

## 🚀 Główne Zalety Chmury (Key Benefits)

* **Scalability (Skalowalność):** Szybkie zwiększanie lub zmniejszanie zasobów w zależności od aktualnego obciążenia systemów.
* **On-demand self-service:** Samodzielne i natychmiastowe uruchamianie potrzebnych usług bez prośby o wsparcie techniczne.
* **Pay-as-you-go (Płatność za użycie):** Model rozliczeniowy, w którym płaci się wyłącznie za faktycznie wykorzystane zasoby.
* **Security & High Availability:** Możliwość wykorzystania mechanizmów bezpieczeństwa oraz zapewnienia wysokiej dostępności dzięki rozproszonej infrastrukturze i usługom dostawcy.
* **Global Access:** Dostęp do zasobów i aplikacji z dowolnego miejsca na świecie posiadającego połączenie z siecią Internet.

## 📌 Podsumowanie w 3 zdaniach
1. Chmura obliczeniowa oferuje elastyczne zasoby w trzech głównych modelach usług (**IaaS**, **PaaS**, **SaaS**) oraz wdrażania (**Public**, **Private**, **Hybrid**).
2. Dostawcy tacy jak **AWS**, **Azure** i **GCP** oferują skalowalne usługi chmurowe, takie jak AWS EC2, umożliwiające uruchamianie instancji obliczeniowych.
3. Przejście do chmury umożliwia wysoką dostępność, globalny dostęp oraz optymalizację kosztów dzięki modelowi rozliczeniowemu **Pay-as-you-go**.

### Chmura obliczeniowa przekształca tradycyjną infrastrukturę IT w elastyczną, skalowalną i opłacalną usługę dostępną na żądanie.
